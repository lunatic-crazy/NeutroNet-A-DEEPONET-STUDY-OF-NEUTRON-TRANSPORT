# Dataset card: NeutroNet final-model data

## Overview

`data/final_model/` contains the only retained dataset collection. Every flux target was generated by the repository's deterministic one-dimensional S32 transport solver.

| File | Cases | Materials | Sources | Purpose |
|---|---:|---|---|---|
| `train.npz` | 2,800 | 1-2 layers | Seven balanced trained families | Parameter fitting |
| `validation.npz` | 350 | 1-2 layers | Seven balanced trained families | Checkpoint selection |
| `test_in_distribution.npz` | 350 | 1-2 layers | Seven balanced trained families | Interpolation test |
| `test_three_layer_ood.npz` | 350 | Exactly 3 layers | Seven balanced trained families | Material-topology OOD |
| `test_unseen_sources.npz` | 600 | 1-2 layers | Six balanced unseen families | Source-shape OOD |

## Trained source families

Each split is balanced across GRF, narrow Gaussian, wide Gaussian, step, sinusoid, multiple-peak, and combination fields. Combination fields superpose a discontinuity, sinusoid, and localized Gaussian component.

The unseen-source benchmark contains linear ramps, exponential layers, triangular tents, sawtooth fields, chirps, and Lorentzian peaks. None of these six construction rules is used in training.

## Arrays

Each NPZ archive contains:

- `x`: cell-center coordinates, shape `(100,)`.
- `Q`: source fields, shape `(cases, 100)`.
- `Sigma_t`: total cross sections, shape `(cases, 100)`.
- `Sigma_s`: scattering cross sections, shape `(cases, 100)`.
- `Sigma_a`: absorption cross sections, `Sigma_t - Sigma_s`.
- `phi`: converged scalar-flux references, shape `(cases, 100)`.
- `layer_count`: material-layer count per case.
- `interfaces`: fixed-width interface-index metadata.
- `solver_iterations`: source iterations used by the reference solver.
- `source_family`: the source construction label.

All generated materials satisfy positive `Sigma_t` and `0 <= Sigma_s < Sigma_t`.

## Generation seeds

The four trained-family splits use base seed 20260920, incremented deterministically by split in `generate_final_dataset.py`. The unseen-source benchmark uses seed 20260921. Complete commands are provided in `README.md`.

## Limitations

The data are synthetic and cover only a 10 cm, 100-cell, one-dimensional slab with vacuum boundaries and the generator ranges encoded in `sources.py` and `materials.py`. Randomly generated cases are not a substitute for established transport benchmarks or application-specific nuclear data.
